# React Fundamentals — Interview Practice

A React + TypeScript interview practice project with a small Express employee directory API.

## Backend

```bash
cd backend
npm install
npm run dev
```

API is available at `http://localhost:3001`.

## Frontend — your interview exercise

Create a Vite React + TypeScript application in `frontend/` and implement the UI yourself. Start with fetching `GET /api/employees`, loading/error states, and displaying employees. We will add filtering, sorting, tests and performance optimizations one round at a time.

See [backend/README.md](backend/README.md) for API routes and verification instructions.
